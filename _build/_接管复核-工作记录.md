## 缺陷（按严重度）
- **D1 高** 全部入口无鉴权且绑 0.0.0.0（HttpServer.java:40、FileReceiver.java:48）→ 同网段可读全量剪贴板(:57)、下载任意文件(:60,315-332)、写剪贴板与相册(:58)、拉起应用(:62)
- **D2 高** FileReceiver.java:87 路径穿越：name 来自网络首部未净化，`../` 可写出目标目录
- **D3 中** 暂停局域网只停 mDNS + 拦 HTTP，FileReceiver 无 sLanPaused ⇒ 35792 仍对 LAN 开放
- **D4 中** BridgeService.java:87,94 PAUSE/RESUME 提前 return 未 startForeground → 未运行时 startForegroundService 5s 超时崩溃
- **D5 中** 剪贴板 sig 双前缀：手机端自带前缀 + main.js:670 再拼一次 → remoteSig「txt:txt:…」永不等于 echoGuard（main.js:620/626/654/671）⇒ **防回环失效**，PC→手机推送后会触发假的 clipboard:remote 并回写 PC 剪贴板
- **D6 中** MainActivity.java:147-150 无视权限结果直接起服务，绕过 :115 的 MANAGE_EXTERNAL_STORAGE 门槛
- **D7 中** /open 用 file:// 且清单无 <provider>（VivoOfficeAdapter.java:19,27-29,43-46）⇒ Android 7+ 目标应用读不到文件
- **D8 中** 剪贴板图片无大小上限；ThumbCache 最多 96 张 480px 从不 recycle，峰值约 88MB
- **D9–D18 低** LOCKED_BOOT_COMPLETED 无 directBootAware；多余权限（ACCESS_WIFI_STATE 隐含 wifi 硬件必需）；/ping 的 name 与 model 都是 Build.MODEL；文件名含 + 无法下载；文本推送被剥首尾引号；ClipboardWatcher 死代码；句柄卫生；冷启动直弹全盘访问设置页；build.ps1 增量污染与会覆盖 app.apk；签名口令硬编码在项目内
